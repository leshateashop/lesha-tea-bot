# Чайная лавка дяди Лёши — Telegram Bot

Первая рабочая версия Telegram-бота без интеграции с МойСклад.

## Что уже есть

- `/start`
- главное меню
- категории каталога
- товары в SQLite
- добавление в корзину
- профиль клиента
- заготовки для заказов, бонусов, избранного и поддержки

## Безопасность

Токен Telegram-бота хранится только в переменной окружения `BOT_TOKEN`.
Не публикуйте его в GitHub и не отправляйте в чат.

## Запуск на Mac

1. Установить Python 3.11+.
2. Распаковать проект.
3. В терминале открыть папку проекта.
4. Выполнить:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

5. Задать токен:

```bash
export BOT_TOKEN="ВАШ_ТОКЕН"
```

6. Запустить:

```bash
python3 bot.py
```

После запуска открыть @LeshaTeaShopBot и отправить `/start`.

## Важно

Пока товары не добавлены в базу. Это специально: следующим этапом мы сделаем удобное добавление реальных чаёв, фотографий, цен и описаний, а затем оформление заказа.
